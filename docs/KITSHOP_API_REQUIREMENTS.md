# KitShop API — какие данные нужны (Phase 2)

**Правило: только чтение.** Наш сервис никогда не создаёт, не изменяет и не удаляет данные в KitShop.
В коде нет ни одного метода записи, даже если API его поддерживает.

Никакие запросы к production не выполняются, пока нет подтверждённой документации по каждому методу
и не включён флаг `KITSHOP_ENABLED=true`.

## Известно сейчас

| Метод | Статус | Что нужно уточнить |
|---|---|---|
| `GetSalesbyShops` | существует | URL, HTTP-метод, формат авторизации (companyId/login/password → токен?), параметры периода, пагинация, формат ответа, часовой пояс дат, есть ли id продажи и id товара |

## Что нужно для полноценной работы

| # | Данные | Зачем | Приоритет | Минимальные поля |
|---|---|---|---|---|
| 1 | **Продажи по точкам за период** (`GetSalesbyShops`) | история, темп, прогноз | критично | id продажи/чека, id точки, id товара, количество, цена, дата-время с часовым поясом |
| 2 | **Текущие остатки по точкам** | риск пустой полки и списаний | критично | id точки, id товара, количество, время снимка |
| 3 | **Справочник точек** | названия, адреса, активность | высокий | id, название, адрес, активна ли, (координаты) |
| 4 | **Справочник товаров** | категория, цена, срок годности | высокий | id, название, группа/категория, цена, (срок годности) |
| 5 | Поставки / пополнения | остатки без метода остатков, план поставок | средний | id точки, id товара, количество, время |
| 6 | Списания | измерение реальных списаний, обучение | средний | id точки, id товара, количество, время, причина |
| 7 | Инкрементальная выборка | не тянуть всю историю | высокий | фильтр `updatedSince`/`fromDate`, пагинация, сортировка |

## Вопросы к владельцу API

1. Базовый URL и схема авторизации? Срок жизни токена?
2. `GetSalesbyShops` — GET или POST? Какие параметры (companyId, dateFrom, dateTo, shopIds)?
3. Максимальный период одного запроса и лимиты частоты?
4. Уникален ли идентификатор продажи? Есть ли возвраты и как они выглядят?
5. В каком часовом поясе даты?
6. Есть ли метод остатков? Если нет — есть ли поставки и списания?
7. Как товар связан с категорией (группа, тег)?

## Как будет подключено

```
KitShop (read) ──► services/kitshop/kitshopClient.ts   (только белый список read-методов)
                 └► services/kitshop/adapter.ts        (маппинг в доменные типы)
                     └► lib/sync/syncEngine.ts         (инкрементально, last_sync_at, upsert по external id)
                         └► наша БД (Sale, InventorySnapshot, HourlyAggregate)
                             └► KitShopDataSource → Engine
```

Переменные окружения (только server-side, файл `.env.local`, в Git не попадает):
```
KITSHOP_ENABLED=false
KITSHOP_API_URL=
KITSHOP_COMPANY_ID=
KITSHOP_LOGIN=
KITSHOP_PASSWORD=
```
